# AI Voice App

A voice-first personal memory assistant for iPhone.

## Product vision

Capture thoughts naturally by voice or text, save links, manage tasks conversationally, and search across a persistent personal memory.

## Planned stack

Expo / React Native for iOS; Supabase for authenticated storage and hybrid search; secure server-side OpenAI integration for transcription, reasoning, and realtime voice.
